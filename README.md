# OptiVault Android

An unofficial Android WebView app for accessing OptiVault more conveniently on Android devices.

The app opens the OptiVault website directly inside an Android application, allowing users to access the service without manually opening a browser and searching for the website.

# 🌐 Website

OptiVault: https://optivault.ai.studio/

# 📱 About this App

This repository contains an Android WebView wrapper created to provide a convenient mobile app experience for the OptiVault website.

The app itself does not recreate, copy, or claim ownership of the OptiVault website or its content. The website is loaded directly from its original source.
